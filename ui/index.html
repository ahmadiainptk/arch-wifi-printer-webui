How this works

Mikrotik client isolation blocks IPv4 unicast between Wi-Fi clients, so CUPS can't reach the printer directly. This app runs a local TCP proxy that bridges 127.0.0.1:<port> → printer's IPv6 link-local address (fe80::…), which is never routed and therefore not blocked. CUPS is pointed at localhost via the socket://-style proxy port.
